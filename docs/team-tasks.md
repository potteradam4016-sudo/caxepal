# 담당별 구현 현황과 남은 작업

2026-09-27 코드 기준입니다. 구현 완료와 운영 승인·실서비스 검수를 구분합니다. 일정·담당자 실명은 GitHub 이슈에서 관리합니다.

## 구현된 기능

- [x] React/Vite/TypeScript 환경과 로그인·회원가입·온보딩 구현
- [x] 실제 FastAPI 인증·프로필·공지·추천·찜·캘린더 연동
- [x] 검색·복수 내용 카테고리·작성자 출처 필터·페이지 이동 구현
- [x] 공지 상세·정보 수정 모달, 로딩·빈 결과·오류·재시도 처리
- [x] 프로필 버전 충돌, 세션 복원·만료, 계정별 데이터 분리 구현
- [x] PostgreSQL 지원과 0001~0003 마이그레이션, 전용 동시성 테스트 코드 추가
- [x] 대표 게시판 단일 수집, 작성자 6종 분류, 최신순 최대 5페이지·40건 수집
- [x] OpenAI 선택적 분석, 규칙 보완·근거 검증·실패 표시·수동 검수 API
- [x] AI·SW 전공 연관성 추천 및 찜 기반 기간 일정 캘린더
- [x] 데스크톱 비례 레이아웃과 모바일 단일 열 구현

최신 화면 기준은 [PC 구현 명세](design/pc/implementation-spec.md)와 React입니다. 기존 HTML·PNG 프로토타입은 레거시 참고 자료입니다. 검증 결과는 [보고서](../backend/docs/TEST_REPORT.md)에 따릅니다.
