# SCNU PICK PC 구현 명세 — API 연동

갱신: 2026-09-26

최신 동작은 React와 [공유 API 계약](../../api-contract.md)을 기준으로 합니다.
기존 HTML·프로토타입 테스트·PNG는 레거시 참고 자료이며 수정하지 않습니다.

## 실행 및 화면 이동

백엔드는 `backend/START.cmd`, 프론트는 `frontend`에서 `npm run dev`로 실행합니다.
기본 포트는 API 3104, 프론트 5173입니다. 계정과 공지의 목 시연 모드는 없습니다.

| 경로 | 동작 |
| --- | --- |
| /login | 서버 로그인, 완료 여부에 따라 추천 또는 등록 단계 이동 |
| /signup | 가입 후 로그인 호출, 성공하면 /academic |
| /academic | 학적을 서버에 저장한 후 /preferences |
| /preferences | 서버 관심사 사전에서 복수 선택 후 전체 프로필 저장 |
| /complete | 서버 저장 결과를 확인하고 /recommend 이동 |
| /recommend | 등록 완료 사용자의 추천 |
| /new | 신규 공지 검색·필터·페이지 이동 |
| /calendar | 현재 월의 찜 일정, 빈 달에도 월 이동 가능 |

세션 복원 중에는 보호 경로를 판정하지 않고 로딩을 표시합니다.
미로그인은 로그인, 학적이 없는 미완료 사용자는 학적 등록, 그 외 미완료 사용자는 관심사 단계로 이동합니다.
가입 후 로그인만 실패한 경우 가입 완료를 안내하여 중복 가입을 방지합니다.

## 인증·프로필

- 아이디: 영문자로 시작하는 소문자·숫자·밑줄 3~32자. 공백 제거·소문자 변환.
- 가입 비밀번호 12~128자와 확인값을 검사하고 로그인은 1~128자를 받습니다.
- 토큰과 만료 시각은 sessionStorage에 저장하며 비밀번호는 저장하지 않습니다.
- 학과 2~80자, 학년 1~6, 학적 재학·휴학·졸업예정·졸업.
- 관심사와 활동은 서버 사전의 ID를 사용하고 각 그룹 최소 1개를 선택합니다.
- 학적 단계는 서버 저장, 관심사 초안은 사용자 ID별 탭 저장, 최종 완료는 서버 응답으로 판정합니다.
- 프로필 수정은 별도 초안과 expected_version을 사용합니다. 충돌 시 초안을 유지하고 최신 정보 불러오기를 제공합니다.
- 저장 성공 후 추천·상세 추천 정보를 갱신하며 찜을 유지합니다.

## 공지·찜·캘린더

- 목록은 서버 3줄 요약, 점수, 추천 이유, 마감 표시를 사용합니다.
- 8종 카테고리를 복수 선택하며 같은 필터 내부는 OR, 검색·출처·마감 필터 사이는 AND입니다.
- 검색 300ms 지연, 최대 100자, 페이지당 20개, 마감 임박 7일을 적용합니다.
- 상세는 모든 신청·행사 일정, 본문, 대상, 신청 방법, 상금, 마일리지, 첨부와 원문을 표시합니다.
- null과 미기재를 임의 날짜·금액으로 바꾸지 않습니다. 마일리지 points_text를 그대로 표시합니다.
- 찜은 서버 계정별 데이터이며 변경 중 중복 요청을 막고 실패 시 복원합니다.
- 캘린더는 서울 기준 현재 월로 시작하고 서버가 반환하는 기간 전체를 표시합니다.
- 신청은 파란색, 행사는 초록색으로 구분하며 월 경계와 일부 날짜 미정·일정 미정을 표시합니다.

## 레이아웃과 검증

기존 브랜드·사이드바·인증 화면의 2560×1440 구성을 데스크톱 기준으로 삼아 화면에 맞게 비례 조정합니다.
가로 680px 이하에서는 글자와 조작 영역을 유지하도록 모바일 단일 열 배치를 사용합니다.
목록은 로딩·오류·빈 상태·재시도 및 페이지 이동을 제공합니다.
모달의 키보드 포커스, Esc 닫기, 필드 라벨과 선택 상태 접근성을 유지합니다.

프론트 lint/typecheck/test:run/build와 백엔드 pytest를 실행합니다.
실제 API 브라우저 테스트는 임시 DB에서 가입·온보딩·추천·찜·프로필 수정·캘린더를 검증합니다.
현재 사용자 DB와 레거시 시연 데이터는 테스트에 사용하지 않습니다.
