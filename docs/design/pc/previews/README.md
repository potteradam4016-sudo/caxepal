# SCNU PICK PC v2 — 레거시 화면 자료

기존 단일 HTML 프로토타입에서 캡처한 **1440 × 1000px** 화면입니다. 이 이미지와 HTML은 현재 아이디 기반 React 계정 정책을 반영하지 않는 시각 참고용 레거시 자료입니다. 최신 동작과 인수 기준은 [구현 명세](../implementation-spec.md)와 React 구현을 따릅니다.

현재 화면 확인은 `frontend` 개발 서버를 실행해 진행합니다. 이 폴더의 PNG는 파일 보존 목적으로만 남기며 신규 구현의 화면 목록이나 기능 범위를 정의하지 않습니다.

글꼴은 캡처 환경에 설치한 Noto Sans CJK KR이며, 실제 PC의 설치 글꼴에 따라 미세한 차이가 있을 수 있습니다.
