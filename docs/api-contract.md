# 프론트와 백엔드 API 합의

아직 확정 명세가 아닙니다. 아래 역할부터 협의하고 실제 경로·필드·예제를 기록합니다. 구현 전에 프론트·백이 같은 문서를 확인합니다.

| 기능 | 요청·응답에서 필요한 내용 | 상태 |
| --- | --- | --- |
| 인증 | 아이디 기반 가입, 로그인, 로그아웃, 세션 조회 | 합의 전 |
| 프로필 | 본인 학과·학년·학적 조회·수정 | 합의 전 |
| 관심사 | 분야·활동 선택지, 선택값 조회·수정 | 합의 전 |
| 추천 | 공지 카드, 추천 점수·이유, 필터 | 합의 전 |
| 신규 | 원문 등록일 기준 목록, 검색·필터 | 합의 전 |
| 상세 | 대상·신청·행사 일정·혜택·원문·찜 여부 | 합의 전 |
| 찜 | 본인 찜 추가·해제 | 합의 전 |
| 캘린더 | 요청 월과 겹치는 찜 공지의 신청·행사 일정 | 합의 전 |

## 공통 합의 항목

- 인증 전달·만료·갱신·로그아웃 처리
- 아이디 중복 확인, 영문 소문자·숫자 4~20자 검증과 정규화
- 날짜만 있는 값과 시간이 있는 값의 표현, 시간대
- 기간이 여러 달에 걸칠 때 조회와 표시 방식
- 날짜·상금·마일리지 미기재와 명시적 없음의 구분
- 목록 페이지 처리, 검색·필터 파라미터
- 정상·빈 결과·유효하지 않은 입력·인증 실패·권한 부족 응답
- 프로필 변경 후 추천 결과 갱신과 캐시 처리

## 개별 API 작성 양식

각 API마다 아래 항목을 복사해 작성합니다.

| 항목 | 기입 내용 |
| --- | --- |
| 기능 | 사용 화면과 목적 |
| Method / Path | 담당자 합의 후 기입 |
| 인증 | 필요 여부와 전달 방식 |
| 요청 | 파라미터·본문·필수 여부 |
| 성공 응답 | 상태 코드와 JSON 예제 |
| 실패 응답 | 오류 코드·메시지·화면 처리 |
| 예외 | 미정 날짜·빈 목록·중복 요청 등 |
| 합의 확인 | 프론트 / 백엔드 |
