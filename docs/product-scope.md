# 확정 기능과 화면 범위

## 사용자 흐름

로그인 → 학적 등록 → 관심 분야·활동 유형 선택 → 추천 공지 메인.

기존 사용자는 등록을 반복하지 않고 메인으로 진입합니다. 학적은 학과·학년·학적 상태를 직접 입력합니다.

## 화면

| 화면 | 핵심 동작 |
| --- | --- |
| 로그인·회원가입 | 아이디 + 비밀번호, 가입 후 바로 최초 등록 |
| 학적·관심사 등록 | 관심 분야·활동 유형을 구분해 복수 선택 |
| 추천 공지 | 첫 메인, 적합도와 실제 추천 이유, 3줄 요약 |
| 신규 공지 | 원문 등록일 기준 최신순 |
| 내 캘린더 | 찜한 공지의 신청·행사 일정, 월간 보기 |
| 공지 상세 | 대상·일정·혜택·원문 링크·찜 |
| 내 정보 수정 | 사이드바에서 여는 모달, 저장 시 추천 갱신, 취소 시 기존 값 유지 |

왼쪽 메뉴는 **추천 공지 / 신규 공지 / 내 캘린더**입니다. 사이드바의 **내 정보 수정**에서 학적·관심사를 수정합니다.

## 추천과 마감

- 학적·관심 분야·활동 유형을 기준으로 추천합니다.
- AI·SW 관련 학과와 공지 주제가 맞으면 지원 자격 확정과 구분되는 전공 연관성 점수를 줄 수 있습니다.
- 최신성·마감 임박은 추천 점수에 포함하지 않습니다.
- 마감 임박은 독립 메뉴 없이 필터와 D-Day 배지로 제공합니다.
- 신청 마감이 지난 공지는 추천 후보에서 제외하되, 찜과 예정된 실제 행사 일정은 유지합니다.
- 현재 구현 배점은 관심 분야 35 / 학과 25 / 학적 15 / 학년 10 / 활동 15입니다. 학과 항목은 명시적 대상 25, 전 학과 12, AI·SW 주제 연관성 10 중 우선되는 하나만 적용합니다. 임박 필터는 7일이며 정책 변경은 팀 검토 후 반영합니다.

## 공지 카드와 혜택

- 가로로 넓은 카드를 세로로 쌓습니다.
- 제목·출처·추천도·추천 이유·D-Day를 표시합니다.
- 3줄 요약은 대상 / 내용 / 일정으로 구성합니다. 중복 항목명·장식 문자는 정리해 표시합니다.
- 상세 모달에는 요약·대상·모집인원·신청 방법·혜택·첨부·원문을 표시합니다. 별도 신청·행사 일정 영역과 공지 본문 영역은 표시하지 않으며 전체 일정은 캘린더에서 확인합니다.
- 마일리지는 제도별 점수·조건을 구분하고 서로 다른 제도 점수를 합산하지 않습니다.
- 상금은 있음·없음·미기재를 구분합니다. 금액과 수상 조건은 원문에 있을 때만 표시합니다.
- 원문에 없는 혜택이나 날짜는 추정하지 않습니다.

## 찜과 캘린더

- 찜한 공지의 신청 시작일·신청 마감일·실제 행사 시작과 종료일을 표시합니다.
- 신청 일정과 실제 행사는 라벨·색으로 구분합니다. 일정 클릭 시 공지 상세로 이동합니다.
- 날짜를 모르면 ‘일정 미정’으로 안내합니다.
- 찜은 관심 표시입니다. 신청 완료 상태를 별도로 관리하지 않습니다.
- 학적·관심사를 바꿔도 기존 찜과 캘린더는 유지합니다.

## 수집 출처

순천대학교 대표 공지만 수집합니다. 작성자 기준 출처 분류는 SW중심대학사업단,
AI인재양성부트캠프사업단, RISE사업단, 산학협력교육센터, 첨단소재광양캠퍼스, 기타입니다.
기타에는 앞의 다섯 작성자에 해당하지 않는 모든 글이 들어갑니다. 공지 내용 분류 8종과는 별개입니다.
과거 SW·AI 별도 게시판 공지와 연결된 찜은 `purge-legacy-notices --apply`로 명시적으로 정리합니다. `init-db`는 이전 출처를 비활성화하지만 공지·찜을 삭제하지 않습니다.

글로컬사업단의 별도 게시판은 수집하지 않습니다. 대표 게시판에 올라온 글은 작성자와 무관하게 수집 대상이며 앞의 다섯 작성자가 아니면 기타입니다. 허가 완료를 가정하지 않으며 [수집 조건](crawling-permission.md)을 별도로 기록합니다.

## 계정과 신청

아이디는 영문자로 시작하는 소문자·숫자·밑줄 3~32자로 만들며 양쪽 공백 제거와 소문자 정규화를 적용합니다. 가입 비밀번호는 12~128자, 로그인 비밀번호는 1~128자이며 브라우저 저장소에 보관하지 않습니다. 세션 토큰은 현재 탭의 sessionStorage에 보관합니다. 실제 신청 및 자격 확인은 각 운영기관의 원문 안내 절차를 따릅니다.

## 아직 정하지 않은 내용

현재 관심사 사전은 분야 8개·활동 7개, 운영 DB는 PostgreSQL, 외부 분석은 OpenAI, 자동 수집 기본 간격은 3시간입니다. 수집 시 최신순 최대 5페이지·40건을 확인하며 기존 공지도 이 한도에 포함됩니다. API는 [연동 계약](api-contract.md)을 따릅니다.

배포 플랫폼·도메인, 수집 허가·운영 조건, 관심사·추천 정책의 팀 승인과 AI 비용 한도는 별도 확인이 필요합니다. 구현된 기본값을 운영 승인으로 간주하지 않습니다.
