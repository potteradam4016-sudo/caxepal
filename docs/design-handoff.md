# SCNU PICK PC 디자인 전달 — v2

**2026-09-21: 전체 요청 화면과 클릭 흐름 구현 완료.** 프론트 담당자 검토 및 실제 서비스/API 구현은 별도입니다.

이번 전달 형식은 **실행 가능한 HTML/CSS/JavaScript 코드 + 화면별 구현 명세**입니다. Figma 파일 또는 자동 변환된 React 코드가 아닙니다. 프론트 담당자는 이 파일의 스타일·화면 동작을 기준으로 `frontend/`에서 React 컴포넌트와 API를 구현하면 됩니다.

## 빠른 확인

1. `feature/frontend-setup` 최신 코드를 받습니다.
2. `docs/design/pc/notice-prototype.html`을 브라우저에서 엽니다. GitHub 파일 화면 자체는 HTML을 실행하지 않습니다.
3. 신규 가입은 `new@example.com` 같은 예시 이메일과 임의의 8자 이상 비밀번호로 시연합니다.
4. 메일 확인 화면에서 **시연 도구 → 메일 확인 성공 시연**을 누르고 학적·관심사를 등록합니다.
5. 기존 사용자 화면만 확인하려면 **시연 도구 → 기존 사용자 로그인 예시**를 누릅니다.
6. 실패 상태는 **시연 도구 → 다음 요청 네트워크 실패**를 켠 후 저장·가입·찜 등을 시도합니다. 정보 수정 실패는 모달을 열기 전에 켭니다.

## 실제 서비스 연결 시 남은 일

- React 화면/라우팅으로 이전하고 실제 인증·메일 발송·비밀번호 검증·복구를 서버에 연결합니다.
- 학과 목록, 관심 분야/활동 유형 목록, 추천 점수·가중치, 마감 임박 기준 일수는 팀에서 확정합니다.
- 실제 원문 URL·혜택·시간대·날짜와 API 계약을 연결합니다.
- 화면 폭에 따른 조정은 프론트 담당자가 진행합니다. 기본 검수 기준은 1440px PC입니다.
- 프론트 담당자의 디자인 확인: **대기**. 서비스 개발 완료 또는 배포 완료를 의미하지 않습니다.
