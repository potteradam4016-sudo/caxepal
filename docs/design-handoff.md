# 디자인 전달

전달 도구는 Figma입니다. 전체 디자인 완료 후 프론트엔드 담당자에게 전달합니다.

| 항목 | 값 |
| --- | --- |
| Figma 링크 | 등록 전 |
| 기준 버전 | 확정 전 |
| 전체 화면 완료 | 미완료 |
| 프론트 전달 여부 | 전달 전 |

## 전달 체크리스트

- [ ] 화면 목록과 이동 경로
- [ ] 로그인·학적·관심사 등록 화면
- [ ] 추천·신규·월간 캘린더·공지 상세 화면
- [ ] 별도 정보 수정 화면의 저장·취소
- [ ] 버튼·입력·카드·필터·찜 상태
- [ ] 로딩·오류·빈 상태
- [ ] 색상·글자·여백·너비와 반응형 적용 범위
- [ ] 이미지·아이콘 에셋과 사용 권한
- [ ] 캘린더 일정 구분 방식과 날짜 미정 안내
- [ ] 이후 변경 내용을 남길 위치

Figma의 숫자·공지·점수·혜택 예시는 실제 데이터와 구분합니다. 세부 수치를 코드 담당자가 추측하지 않도록 확정본에 기록합니다.

## 변경 기록

| 일자 | 변경 화면 | 내용 | 프론트 확인 |
| --- | --- | --- | --- |
| 작성 시 입력 | 해당 화면 | 변경 전후와 이유 | 확인 전/완료 |
