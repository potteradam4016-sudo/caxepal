# 대표 공지 수집 허가 확인표

2026-09-27 문서 감사에서 승인 증빙을 확인하지 못했습니다. 아래 빈 항목은 허가 완료를 뜻하지 않습니다. 이미 받은 승인이 있다면 담당자가 범위와 증빙 위치를 기록합니다. 개인정보가 포함된 메일 원문·담당자 연락처는 공개 저장소에 올리지 않습니다.

| 항목 | 확인 상태 |
| --- | --- |
| 대상 | 순천대학교 대표 공지, SCNU_MAIN, mi=1131 / bbsId=1040 |
| 담당 부서·문의 창구 | 확인 필요 |
| 문의일·답변일·확인 담당자 | 기록 필요 |
| 승인 여부와 비공개 증빙 위치 | 확인 필요 |
| 허용 경로·항목·재게시 범위·출처 표시 | 확인 필요 |
| 자동 수집 주기·요청 간격·건수 | 승인 조건 기록 필요 |
| 본문 외부 AI 전송·요약 표시 허용 범위 | 확인 필요 |
| 보관 기간·수정·삭제 요청 처리 | 확인 필요 |
| robots 예외의 명시적 서면 허가 | 예외 사용 시 별도 확인 필요 |

현재 코드 기본값은 수집 OFF, 자동 수집 OFF, robots strict입니다. 활성화 시 기본 주기는 3시간, 요청 간격은 최소 1초, 최신순 최대 5페이지·40건입니다. 이 값은 기술적 기본값이지 학교가 승인한 조건이 아닙니다.

SW·AI의 별도 게시판은 수집하지 않습니다. 대표 게시판의 글은 작성자 제한 없이 대상이며 작성자별 표시를 6종으로 나눕니다. 첨부파일 다운로드·OCR은 하지 않습니다.

robots 허용이나 과거 수집 성공만으로 허가를 대신하지 않습니다. 조건을 확인한 뒤 [수집 설정](../backend/docs/CRAWLER_AND_AI.md)에 반영하고 [배포 확인 목록](deployment-checklist.md)을 갱신합니다.
