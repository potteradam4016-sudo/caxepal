# Frontend

React 화면 구현 위치입니다. 현재는 초기 안내만 있고 앱·의존성·실행 명령은 아직 없습니다.

## 첫 작업

1. `feature/frontend-setup`에서 React 실행 환경을 구성합니다.
2. 빌드 도구, JS/TS, 패키지 관리자는 백엔드와 연결 방식을 확인한 뒤 팀에 공유합니다.
3. 이 README에 필요한 런타임 버전, 설치·실행·빌드 명령을 기록하고 사용한 잠금 파일을 커밋합니다.
4. 비밀값이 없는 `.env.example`을 추가합니다. 브라우저에 포함되는 환경변수에는 서버 비밀키를 넣지 않습니다.
5. 환경 구성 PR을 `dev`로 보냅니다.

## 화면 구현 시작 조건

PC 디자인 v2의 전체 화면과 클릭 흐름이 완료되어 있습니다. [디자인 전달 문서](../docs/design-handoff.md)의 HTML 프로토타입과 구현 명세를 확인한 뒤 React로 구현합니다. HTML 파일은 참고용 실행 코드이며, Figma 링크나 React 앱 자체는 아닙니다. 화면 크기별 조정과 실제 API 연결은 프론트 담당자가 진행합니다.

## 구현 범위

- 이메일 로그인·회원가입·메일 확인·비밀번호 재설정
- 학적 등록, 관심 분야·활동 유형 복수 선택
- 추천 공지 메인, 신규 공지, 월간 내 캘린더
- 공지 상세·찜하기, 마감 임박 필터·D-Day
- 학적·관심사 별도 수정 화면
- 로딩, 오류, 빈 결과, 찜한 일정 없음 상태

API 경로와 응답 형식은 [API 합의 문서](../docs/api-contract.md)에서 백엔드 담당자와 확정합니다. 데모 데이터를 쓰는 동안에는 실제 API 연결 완료로 표시하지 않습니다.
