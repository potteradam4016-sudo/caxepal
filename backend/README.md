# Backend

FastAPI 서버 구현 위치입니다. 현재는 초기 안내만 있고 서버·의존성·DB는 아직 없습니다.

## 첫 작업

1. `feature/backend-setup`에서 FastAPI 실행 환경을 구성합니다.
2. Python 버전, 의존성 관리 방식, 설치·실행 명령을 이 README에 기록합니다.
3. 프론트와 인증·오류 응답·날짜 표현을 합의하고 [API 문서](../docs/api-contract.md)를 작성합니다.
4. DB와 인증·메일 발송 구현 도구는 제안 후 팀에서 결정합니다.
5. 필요한 변수명만 `.env.example`로 공유하고 환경 구성 PR을 `dev`로 보냅니다.

디자인 진행 중에도 확정 기획을 바탕으로 API·DB 설계와 개발을 진행합니다.

## 담당 범위

- 이메일·비밀번호 인증, 메일 소유 확인, 비밀번호 재설정
- 프로필·관심사 조회·수정과 본인 데이터 접근 제한
- 허가 범위 내 세 출처 공지 수집·중복 방지·원문 변경 반영
- 공지 구조화·3줄 요약·혜택 구분
- 학적·관심사 기반 추천 및 이유 생성
- 찜 관리와 월간 일정 조회

학생 인증·학적 자동 조회는 하지 않습니다. 신청 마감이 지나도 찜한 실제 행사 일정은 유지해야 합니다. 실제 신청은 원문으로 연결합니다.

크롤러의 운영 수집은 [허가 진행표](../docs/crawling-permission.md)에 확인된 조건을 반영합니다.
