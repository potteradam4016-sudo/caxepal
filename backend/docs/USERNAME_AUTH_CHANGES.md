# 아이디 인증 전환 변경 내역

아이디 인증으로 전환한 `0002` 단계의 변경 기록입니다. 현재 최신 스키마는 작성자 분류를 추가한 `0003`입니다. 폴더를 통째로 교체하지 말고 Git 변경분과 마이그레이션을 적용하며 기존 개인 `.env`·DB는 보존합니다.

| 파일·영역 | 이전 | 현재 |
| --- | --- | --- |
| `app/schemas.py`, `app/api/auth.py` | 주소 형식 입력, 소유 확인 후 로그인 | `username`·`password`로 가입 즉시 로그인 |
| `app/models.py`, `migrations/` | 계정 주소·확인 상태·작업 토큰 테이블 | 고유 아이디와 비밀번호 해시, 세션 테이블 |
| `app/security.py`, `app/services/profiles.py` | 확인 상태 검사와 주소 응답 | 아이디 기반 사용자 응답 |
| `app/services/rate_limit.py` | 주소별 로그인 제한 | 아이디·접속 IP별 로그인 제한 |
| `app/config.py`, `.env.example`, `requirements.txt` | 발송 설정과 주소 검증 의존성 | 관련 설정·의존성 제거 |
| `app/cli.py` | 주소 기준 관리자 지정과 발송 내용 조회 | `grant-admin --username` |
| `app/services/mail.py` | 확인·복구 발송 | 미사용 레거시 파일은 남아 있지만 현재 인증 API에서 호출하지 않음 |
| `tests/`, `scripts/verify_backend.py` | 확인 링크·발송 내용에 의존 | 가입·로그인·현재 비밀번호 확인·세션 폐기 검증 |
| `docs/openapi.json`, `docs/*.md`, `docs/requests.http` | 이전 인증 경로와 예시 | 현재 API와 아이디 예시 |

## 계정 전환

`0002_username_auth`는 기존 DB에서 주소의 `@` 앞부분이 아이디 규칙에 맞고 중복되지 않으면 그 값을 소문자로 사용합니다. 맞지 않거나 충돌하면 `user_` 뒤에 계정 ID 일부를 붙인 임시 아이디를 사용합니다. 주소·확인 상태·작업 토큰 기록은 제거하고 비밀번호 해시와 세션은 유지합니다. 기존 계정 사용자는 전환 후 자신의 아이디를 확인해야 합니다. 배포 전에 계정별 전환 아이디를 안전한 방법으로 안내하거나, 기존 계정을 새로 만드는 운영 방침을 정하세요.

## 비밀번호 정책

로그인한 사용자는 API에 현재 비밀번호를 제출해 새 비밀번호로 변경할 수 있습니다. 현재 React에는 비밀번호 변경 화면이 없습니다. 성공 시 모든 기존 세션이 폐기됩니다. 비밀번호를 잊어 로그인할 수 없는 경우에는 셀프 복구를 제공하지 않습니다. 계정 소유 확인 절차 없이 관리자 임의 재설정 기능을 넣지 않았습니다.
