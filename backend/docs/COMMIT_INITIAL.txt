feat(backend): SCNU PICK 백엔드 초기 기능 구현

서비스 기획에 맞춰 프론트엔드 연동을 위한 백엔드 초기 구현을 추가한다.

- FastAPI 실행 환경, DB 모델 및 마이그레이션 구성
- 이메일 인증, 세션 기반 로그인, 학적·관심사 API 구현
- 공지 조회·검색·추천, 찜 및 월간 캘린더 API 구현
- 대표·SW·AI 세 출처의 공지 수집·분석 파이프라인 추가
- 본인 데이터 접근 제한, 입력 검증 및 요청 횟수 제한 적용
- 최초 실행 시 DB 경로 생성과 실행 오류 처리 보완
- 한국어 문서, API 명세, 자동 테스트 및 HTTP 통합 검증 도구 추가

검증
- 자동 테스트 106개 통과
- 실제 localhost:3104 서버의 HTTP 요청 55개가 기대 결과와 일치
- 새 DB 초기화·반복 실행·스키마 일치 및 문서·API 명세 일치 확인

범위와 남은 확인
- 프론트엔드와 실제 서비스 데이터는 포함하지 않음
- 기본 수집은 비활성화, 메일은 로컬 파일, 분석은 규칙 기반
- Windows 실행·새 가상환경 온라인 설치·실수집·SMTP·AI·PostgreSQL·배포는 별도 확인 필요
- 인증 방식·추천 정책·API 계약은 팀 검토 후 확정
